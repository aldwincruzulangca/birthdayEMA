## Documentation:
6. `README.md` - Project documentation

## How to Push:

1. Stage all files:
   ```
   git add .
   ```

2. Commit the changes:
   ```
   git commit -m "Add birthday invitation website"
   ```

3. Push to remote repository:
   ```
   git push origin main
   ```

The website will be accessible at: https://aldwincruzulangca.github.io/birthdayEMA
