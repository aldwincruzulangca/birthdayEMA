# Birthday Invitation Website

This is a simple, responsive birthday invitation website created for [Name]'s special day.

## Features

- Responsive design that works on all devices
- Interactive RSVP form
- Celebration animations and effects
- Clean, festive styling

## How to Use

1. Fill in your name and email in the RSVP form
2. Click "Confirm Attendance" to submit your response
3. Your RSVP will be received and confirmed

## Files Included

- `index.html` - Main page structure
- `style.css` - Styling and layout
- `app.js` - Interactive JavaScript functionality

## Customization

To customize this invitation:

1. Update the event details in `index.html`
2. Modify colors and styling in `style.css`
3. Adjust JavaScript behavior in `app.js`

## Development

This project uses:
- HTML5
- CSS3 (with gradients and animations)
- Vanilla JavaScript
